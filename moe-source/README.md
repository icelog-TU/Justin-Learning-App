# 教育部《成語典》原始資料

- **來源**：中華民國教育部《成語典》文字資料庫（`dict_idioms_2020_20260625.xlsx`）
- **下載頁**：教育部「辭典公眾授權網」（`language.moe.gov.tw`）
- **授權條款**：創用 CC「姓名標示－禁止改作 3.0 台灣」授權條款（CC BY-ND 3.0 TW）

## 授權重點

- 可以重製、散布、傳輸及供商業利用。
- **不可以修改內容**：不能把教育部撰寫的釋義、典故等文字改寫後當作教育部的原文使用。
- 使用時必須標示來源（教育部《成語典》）。

## 這份原始檔案在專案中的角色

這個資料夾裡的檔案是**未經修改的原始資料**，只用來在開發時產生 `public/data/moe-idioms.json`（成語接龍功能使用的精簡索引），本身**不會被打包進網站**。

`public/data/moe-idioms.json` 只從原始資料中**擷取**（不修改文字內容）以下欄位：

- `word`：成語（原文照抄）
- `meaning`：教育部「用法說明－語義說明」欄位的原文（未經改寫）
- `firstChar` / `lastChar`：成語首尾字
- `firstZhuyin` / `lastZhuyin`：教育部「注音」欄位拆解出的首尾字注音（原文照抄，未改寫讀音）

App 中顯示教育部資料時會標示「資料來源：教育部《成語典》」。
