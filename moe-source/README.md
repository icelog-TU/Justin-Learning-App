# 教育部《成語典》原始資料

## 1. 成語典正文（`dict_idioms_2020_20260625.xlsx`）

- **來源**：中華民國教育部《成語典》文字資料庫
- **下載頁**：教育部「辭典公眾授權網」（`language.moe.gov.tw`）
- **授權條款**：創用 CC「姓名標示－禁止改作 3.0 台灣」授權條款（CC BY-ND 3.0 TW）
- 收錄 5489 筆資料，其中 1642 筆為 4 字「主條成語」，含官方注音與釋義。
- 精簡後輸出成 `public/data/moe-idioms.json`（word / firstChar / firstZhuyin / lastChar / lastZhuyin / meaning，`meaning` 為教育部「用法說明－語義說明」欄位原文照抄）。

## 2. 編輯總資料庫（`dict_idioms_editorial_database.csv`）

- **來源**：教育部《成語典》網站「辭典附錄／編輯總資料庫」
- 這是編輯《成語典》時參考的 **30 種坊間成語工具書** 彙整而成的詞目清單（不是正式收錄的《成語典》內容），共 48,030 筆，只有「詞語」「出處（書目）」「頻次（幾本書收錄）」，**沒有注音、沒有釋義**。
- 官方註記：工具書「兼具正簡版本，用字參差，部分條目或見重複，使用時須多加留意」。

### 篩選規則（產出 `public/data/editorial-idioms.json`）

1. 只保留 4 字詞。
2. 頻次（30 本工具書中出現的本數）**至少 4 本**，過濾掉太冷僻、不重要的條目（原本門檻是 2 本，後來覺得沒有意義的詞太多，拉高到 4 本）。
3. 排除已經在 `idiomChain.ts`（我們手寫的）或 `moe-idioms.json`（教育部正式收錄）裡出現過的詞，避免重複。
4. 首尾字的注音，必須能在「教育部成語典 1642 筆資料」或我們自建的注音對照表（`src/lib/zhuyin.ts`）裡查得到才收錄——**沒有把握的讀音一律不收**，不用猜的。

篩選後剩下 3842 筆，並保留原始的「頻次」欄位輸出到 `public/data/editorial-idioms.json`。這一層**沒有釋義**，一樣可以拿來當提示（沒有解釋的一樣有「查意思」的 Google 連結），但排序時等級較低——詳見下方「提示等級」。

## 3. 提示等級（成語分級）

為了讓提示優先顯示比較「重要」的成語，`src/lib/chainGame.ts` 的 `qualityLevel()` 把每個成語分成三級：

- **🥇 精選（3 級）**：`moe`（教育部《成語典》正式收錄，有官方典故／釋義）與 `curated`（我們手寫的常用成語）皆屬此級；家長／小孩自己新增且有填寫意思的 `custom` 詞也算這級。
- **🥈 常見（2 級）**：`editorial` 且頻次（30 本工具書中出現本數）**≥ 10** 本。
- **🥉 罕見（1 級）**：`editorial` 且頻次為 4～9 本；沒有填寫意思的 `custom` 詞也歸這級。

提示的排序邏輯（`rankHintCandidates()`）先依「同字／同音」比對品質分組，同一組裡再依上述等級由高到低排序，最後才在同等級內隨機洗牌一次；畫面上用分頁瀏覽（上一頁／下一頁／頁碼）而不是每次重新洗牌，翻頁就能看到還沒看過的成語，等級高的仍然優先出現在前面幾頁。
