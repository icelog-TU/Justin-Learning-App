# Justin 的中文練功房

一個為國小三年級學生打造的中文學習網頁應用，主要練習兩個部分：

- **成語**：超過 90 則適合三年級程度的成語，可以瀏覽意思、例句和典故小故事，並透過選擇題測驗與造句練習（附自動檢查）來熟悉用法。
- **錯別字**：依照教育部公開的常用字資料，整理成 37 組形近字／音近字／部件家族（例如「在／再」「的／得／地」「青字家族：睛晴清請情」），共約 90 題造句填空測驗。

所有學習進度（分數、連續天數、答對紀錄、造句紀錄）都保存在瀏覽器的 `localStorage`，不需要帳號、不需要伺服器。

## 開發

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
```

## 技術

React + TypeScript + Vite + Tailwind CSS + React Router，純前端靜態網站，可以部署到任何靜態網站託管服務（例如 GitHub Pages）。
